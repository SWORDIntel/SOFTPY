# SOFTPY licensing history — SRSL-1.1 (2026-10-17)

Original SWORD-owned SOFTPY software first distributed with this release is offered under [SRSL-1.1](LICENSE), a source-available licence. The full earlier [SRSL-1.0 text](LICENSES/SRSL-1.0.txt) is retained.

## Previous MIT metadata and earlier rights

Older `pyproject.toml` declared `license = {text = "MIT"}` and `License :: OSI Approved :: MIT License`, while the root `LICENSE` said SRSL-1.0. The current packaging metadata is aligned **prospectively** to the root SRSL-1.1 licence. It does not purport to revoke independently valid MIT licences or SRSL-1.0 grants already acquired by earlier recipients. The earlier author/contributor and publication history should be reviewed before legal enforcement.

Third-party code and independently licensed components retain their existing terms. The new source-available terms expressly enumerate permitted non-commercial purposes, reserve for-profit internal use, and restrict protected-source training except to the extent statutory rights require otherwise. The 50% profit-sharing figure remains a separately negotiated contractual proposal, not automatic unlicensed-use damages.

Only licence and Python package metadata are changed; no cryptographic implementations, algorithm implementations, runtime execution, permissions, build toolchain or telemetry is changed. Neither this document nor the licence revision establishes cryptographic certification or safety.
